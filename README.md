# С днем рождения, пап ❤️

Поздравительная открытка — обычный статический сайт.
Ничего устанавливать не нужно: только HTML, CSS, JavaScript и фотографии.

---

## Что внутри

```
index.html                        ← главная страница (должна лежать в корне!)
README.md                         ← этот файл
.nojekyll                         ← служебный файл для GitHub Pages
assets/
  css/style.css                   ← оформление
  js/main.js                      ← анимации и кнопка музыки
  audio/ambient.mp3               ← тихая фоновая мелодия
  images/photo-01.jpg … photo-05.jpg   ← фотографии
  images/favicon.png              ← иконка сайта
```

**Самое важное:** файл `index.html` должен лежать **в корне репозитория**, а не внутри
папки `birthday`. Тогда GitHub Pages откроет его автоматически.

---

## Как опубликовать. По шагам

### Шаг 1. Создать репозиторий

1. Зайдите на **github.com** и войдите в аккаунт (или зарегистрируйтесь — это бесплатно).
2. Нажмите зелёную кнопку **New** (или «+» в правом верхнем углу → **New repository**).
3. В поле **Repository name** напишите: `birthday`
4. Ниже выберите **Public**.
5. Нажмите **Create repository**.

### Шаг 2. Загрузить файлы

1. На странице нового репозитория нажмите ссылку **uploading an existing file**
   (или **Add file** → **Upload files**).
2. Откройте распакованную папку `birthday` у себя на компьютере.
3. Выделите **содержимое** папки — то есть `index.html`, `README.md` и папку `assets`
   — и перетащите их в окно браузера.

   ⚠️ Перетаскивайте именно содержимое, а **не саму папку `birthday`**.
   В репозитории `index.html` должен оказаться на самом верху списка файлов.

4. Дождитесь, пока все файлы догрузятся (внизу появится список).
5. Нажмите зелёную кнопку **Commit changes**.

> Файл `.nojekyll` может не показаться при перетаскивании, потому что он скрытый.
> Ничего страшного — сайт работает и без него.

### Шаг 3. Включить GitHub Pages

1. В репозитории откройте вкладку **Settings** (шестерёнка, сверху справа).
2. В левом меню выберите **Pages**.
3. В блоке **Build and deployment**, в поле **Source**, выберите **Deploy from a branch**.
4. Ниже, в поле **Branch**, выберите **main**, а рядом — папку **/ (root)**.
5. Нажмите **Save**.

### Шаг 4. Получить ссылку

Подождите 1–2 минуты и обновите страницу **Settings → Pages**.
Сверху появится зелёная надпись с адресом:

```
https://ВАШ-ЛОГИН.github.io/birthday/
```

Это и есть готовая ссылка. Её можно открыть на телефоне и отправить папе.

## Если что-то пошло не так

**Открывается пустая страница или список файлов.**
Значит `index.html` лежит внутри лишней папки. Откройте репозиторий: если видите папку
`birthday`, зайдите в неё, и перенесите файлы на уровень выше — либо удалите всё и
загрузите заново, перетаскивая содержимое папки, а не саму папку.

**Фотографии не видны.**
Проверьте, что в репозитории есть папка `assets/images` и внутри неё пять файлов
`photo-01.jpg` … `photo-05.jpg`. Имена должны быть строчными буквами, без пробелов.

**Изменения не появляются.**
GitHub Pages обновляет сайт около минуты. Обновите страницу или откройте её в режиме
инкогнито.

**Музыка не играет на iPhone.**
Она включается только по нажатию круглой кнопки под словами «Спасибо за жизнь.» —
так работает Safari, автозапуск он блокирует. Если кнопка нажата, а звука нет,
проверьте боковой переключатель беззвучного режима на телефоне.
